Explanation:
Selecting Elements:

const tabs = document.querySelectorAll('.tab-btn');: This selects all the buttons with the class .tab-btn. These are the buttons you click to switch between the tabs ("history," "vision," "goals").
const contents = document.querySelectorAll('.content');: This selects all the content sections with the class .content. These are the sections that hold the content for each tab.
Adding Event Listeners:

tabs.forEach(function (tab) {...}): This loops through all the tab buttons and attaches a click event listener to each one.
When a button is clicked, the function runs to handle the switching of tabs.
Getting the Data ID:

const id = tab.dataset.id;: Each button has a data-id attribute (e.g., data-id="history"). This line grabs the value of the data-id of the clicked button. This value corresponds to the id of the content section we want to display.
Handling Active State:

Removing 'active' class from buttons: tabs.forEach(function (btn) { btn.classList.remove('active'); });
This loop removes the active class from all buttons. The active class makes the button look visually highlighted, so this step ensures that only one button is active at a time.
Adding 'active' class to the clicked button: tab.classList.add('active');
After removing the active class from all buttons, we add the active class to the button that was just clicked.
Switching Content:

Removing 'active' class from all content sections: contents.forEach(function (content) { content.classList.remove('active'); });
This loop removes the active class from all content sections, effectively hiding them.
Showing the correct content:
javascript
Copy code
const element = document.getElementById(id);
element.classList.add('active');
This part grabs the content section that matches the id of the clicked button (e.g., history, vision, or goals) and adds the active class to it, making it visible.
Key Concepts:
classList.add() and classList.remove(): These methods are used to toggle the visibility of buttons and content by adding or removing the active class.
data-id Attribute: This allows each button to be linked to a specific content section without hardcoding which button affects which content directly.
getElementById(): This method is used to find the corresponding content section by its id, which matches the data-id from the clicked button.
Result:
When a tab button is clicked, its associated content section becomes visible, while the other sections are hidden. The clicked tab button is visually highlighted by the active class, and the rest of the buttons lose that class.
Example in Action:
If you click on the "Vision" tab, the following happens:
The Vision button gets the active class, and other buttons lose it.
The "Vision" content section becomes visible (#vision gets the active class), and the "History" and "Goals" sections are hidden.
